I'm a **Python developer** and current **M.Tech candidate in Artificial Intelligence** at Vidya Pratishthan's College of Engineering, Baramati. ## 🚀 Featured Projects

### 🌏 VibeTranslate — Multi-Agent Translation for Long-Form Web Novels

A multi-agent translation + post-editing pipeline for long-form Chinese web novels. Comprises
**Extractor, Translator, Editor and Context Manager** agents with a persistent glossary, Pydantic
schemas and a BeautifulSoup fallback for robust HTML handling.

- **Technologies:** Python, LLM APIs, Pydantic, BeautifulSoup, agent orchestration
- **Design:** stateful context + glossary so terminology and voice stay consistent across a whole book

---

### 💳 Credit-Card Fraud Detection Pipeline

End-to-end fraud-detection pipeline on a **0.17% positive-class** imbalance.

- **Techniques:** leakage-free split, RobustScaler, SMOTE-in-fold, Random Forest / XGBoost / DNN, voting + stacking
- **Validation:** Youden's J threshold selection and McNemar significance testing

---

### ☕ Coffee-Franchise Agents on Cloud Run

Built during the **Google Cloud Gen AI Academy — APAC Edition, Cohort 3**: a fictional coffee shop scaled
from one location to a national franchise using AI agents on Cloud Run.

- **Lab 1:** RAG barista agent that remembers preferences and recommends blends
- **Lab 2:** Demographic / Real-Estate / Competitor agents collaborating via **BigQuery MCP Server**
- **Lab 3:** Pub/Sub manager agent for automated operations at scale
- **Technologies:** Gemini SDK, Google ADK, BigQuery, Pub/Sub, Cloud Run

---

### 🗣️ Code-Mixed Hinglish Hate Speech Detection

A 7-day course activity comparing a classical **TF-IDF + LinearSVC** baseline against a **context-aware
MuRIL** transformer, with a fairness contract, bootstrap CIs and McNemar testing.

- **Models:** B0 (TF-IDF + LinearSVC) vs A0 (`google/muril-base-cased` + context)
- **Evaluation:** Macro-F1, MCC, balanced accuracy, 95% bootstrap CI, McNemar

[View repository](https://github.com/Lazy-Master/hinglish-hate-detection)
