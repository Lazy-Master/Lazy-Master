## 👋 About Me

I am an **M.Tech (AI & Data Science)** researcher building systems that make machine translation
work for **low-resource Indian languages** and **literary-scale text**.

My current focus is a **multi-agent neural machine translation** pipeline for **ultra-long literary
texts** — decomposing a novel-length source into coherent segments, translating them with
context-aware agents, and re-assembling them without losing voice or narrative continuity. I care
about evidence-based evaluation, reproducibility, and writing that reads like a human wrote it.

- 🎓 M.Tech candidate in Artificial Intelligence & Data Science
- 🔭 Researching multi-agent NMT for ultra-long literary texts (English → Indian languages)
- 🧠 Interested in code-mixed NLP, hate-speech detection and low-resource MT
- 📚 Building a rigorous, reproducible literature-review workflow
- 🌱 Currently exploring agent orchestration, long-context modelling and evaluation methodology

## 🚀 Featured Projects

### 🗣️ Code-Mixed Hinglish Hate Speech Detection

A 7-day course activity comparing a classical **TF-IDF + LinearSVC** baseline against a
**context-aware MuRIL** transformer for romanised Hinglish hate speech, with a strict fairness
contract, bootstrap confidence intervals and McNemar significance testing.

- **Models:** B0 (char n-gram TF-IDF + LinearSVC) vs A0 (`google/muril-base-cased` + conversational context)
- **Evaluation:** Macro-F1, MCC, balanced accuracy, 95% bootstrap CI, McNemar's test
- **Dataset:** HASOC 2021 ICHCL / `nikitadesai/hasoc` (CC-BY-NC-4.0)
